One-time setup

This app relays play / pause / seek events through a free Supabase project — nobody's video file ever leaves their computer. Paste in your project's URL and publishable key once; they're saved in this browser only.

Don't have a project yet? Create one free at supabase.com — Project Settings → API Keys gives you both values (use the Publishable key, not the secret key). No credit card, no server to deploy.
